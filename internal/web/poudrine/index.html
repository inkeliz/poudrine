Report installed packages

Run this in a root sh shell to report this client’s installed package names, versions and port origins. The administrator can see the full report. Poudrine tracks matching ports without downloading the packages.

OpenSSL creates an Ed25519 key on the first run and uses it to sign the report. Keep /var/db/poudrine-client/inventory.key on this client for future reports.
